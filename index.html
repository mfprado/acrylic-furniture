Open Source Modular Furniture

Open source furniture

Furniture you size yourself, from parts you can buy anywhere.

Standard rods, profiles, clamps and sheets, snapped together into shelves, desks, lamps or anything modular you can design, sized to fit your space. Set the dimensions and get the parts list, cut list, 3D preview and a step-by-step PDF build guide.

How it works

  1. Pick a piece

    A shelf or a desk today, and whatever the community designs next: lamps, stools, anything modular. Each one is a small kit of standard parts.

  2. Set your sizes

    Type the width, depth and height you need. It checks sag and load as you go and adds supports when they're needed.

  3. Buy and build

    Take the parts list shopping, send the cut list to a cutting service and follow the PDF.

Contribute

You don't need to code to add a piece.

Designers are welcome. An AI agent does the programming; you make the design decisions. It writes a design brief with you, builds the page, the 3D model and the PDF, and opens the pull request.

Read the contributor guide Open on GitHub
  1. In the Claude desktop app, open Code on your computer.
  2. Ask it to clone this repository and start working there.
  3. Design together in small steps, with a screenshot after each one, then review the pull request.
