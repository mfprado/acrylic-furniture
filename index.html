Open Source Modular Furniture

An open source furniture project. Think of it as Lego for adults: standard rods, profiles, clamps and sheets you can buy anywhere, snapped together into furniture you size yourself. Set the dimensions and get the parts list, cut list, 3D preview and a PDF build guide. Free, and the code is on GitHub.

Ideas for pieces that are not in the configurator yet, as they were suggested. Working out the parts and the build is up to whoever designs one.

Have an idea? Open an issue on GitHub.
